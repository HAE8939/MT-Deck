# Prompt

Rewrite the following raw meeting notes into a structured summary with exactly four sections: Decisions, Open Questions, Action Items (with owner and due date), and Risks. Keep the original language of the notes. Do not invent facts that are not in the notes; if information is missing, mark it as "未确认".

# Notes

Paste the raw notes below the prompt when using it.
